Put the LEBRON CSVs from BBall Index's LEBRON database here (its CSV button), one per season, e.g.
`lebron-data-2026.csv` for 2025-26 (the Season column is the year the season ends). Files need the
nba_id, Season, O-LEBRON and D-LEBRON columns; OffRole and DefRole are shown on the website.
CSVs in this folder are git-ignored. Run `python -m rosterfit check` to see which seasons were picked up.
