Put the Basketball-Reference contracts table here for the website's cap game. On
https://www.basketball-reference.com/contracts/players.html use Share & Export -> "Get as Excel
Workbook" (or "Get table as CSV") and save the file in this folder; any name works
(e.g. `contracts_2026-27.xls`). Tables saved here are git-ignored.
`python -m rosterfit export-web` uses the newest file here and prints how many players made the deck.
